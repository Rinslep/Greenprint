## Step 15 — Pipeline Orchestrator

### 15.0: Define `PipelineResult` dataclass

```python
@dataclass
class PipelineResult:
    success: bool
    blueprint_ids: list[str]       # IDs of saved blueprints (may be >1 for books)
    rejected: bool                  # True if rejected at decode/version/mod stage
    rejection_reason: str | None
    flags: list[dict]               # Aggregate of all flags across all stages
    review_queue_items: int         # Count of items added to the review queue
    errors: list[str]               # Non-fatal stage errors encountered
```

### 15.1: `pipeline/orchestrator.py` — New File

Single entry point `process_string(raw, source_url, source_site, author_raw) → PipelineResult`:

1. SHA-256 hash → dedup check
2. `decode()` → handles books (dissolved into list)
3. For each decoded blueprint:
   - `validate()` → schema + semantic
   - `check_version()` / `check_modded()` → reject or flag
   - `detect_broken()` → flags
   - `infer_recipes()` → flags + review queue
   - `build_crafting_graph()` → summary
   - `analyse_ratios()` → summary
   - `build_lane_model()` → `analyse_throughput()` → summary
   - `extract_motifs()` → `canonicalise()` → `save_motif()`
   - `save_blueprint()` with all flags and summary

**Fraction serialisation:** Define `_serialise_summary(summary: dict) -> dict` that recursively converts any `Fraction` value to `float` before storage. Handles top-level, nested dicts, and lists. Do NOT convert inside analysis modules — only at the storage boundary.

**Per-stage error handling:**

| Stage | Failure behaviour |
|---|---|
| `decode()` | Abort — nothing to work with |
| `validate()` | Abort — corrupted data |
| `check_version()` / `check_modded()` | Abort — explicitly out of scope |
| `detect_broken()` | Continue — attach flags, proceed |
| `infer_recipes()` | Continue — attach flags, queue items, proceed |
| `build_crafting_graph()` | Continue — log warning, store empty graph |
| `analyse_ratios()` | Continue — log warning, store empty ratios |
| `build_lane_model()` | Continue — log warning, skip throughput |
| `analyse_throughput()` | Continue — log warning, store empty throughput |
| `extract_motifs()` / `canonicalise()` | Continue — log warning, no motifs stored |
| `save_blueprint()` | Abort — if we can't save, the whole run is wasted |

Every caught exception must produce a log entry with blueprint hash and source URL.

Wire `BaseScraper._on_new_blueprint()` to call `process_string()`.
